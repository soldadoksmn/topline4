# Topline

Topline is a social video and community application. This repository contains the Android Jetpack Compose client and the Node.js/Express backend.

## Project layout

- `ToplineAndroid/` — Android app (Kotlin, Jetpack Compose, Media3/ExoPlayer).
- `ToplineMobile-saver/server/` — Express API and MongoDB models/routes.
- `render.yaml` — Render service configuration.

## Video feed

The Home screen uses a vertically paged feed and the existing Media3 player lifecycle. The production For You feed now uses API posts only; placeholder/demo videos have been removed. Upload remains connected to the existing post creation flow.

## Configuration

### Backend (Render)

The Render blueprint in `render.yaml` creates the `topline-api` service. Configure these values in the Render service environment:

- `MONGODB_URI` — required MongoDB connection string.
- `JWT_SECRET` — generated by the Render blueprint; keep it private.
- `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, and `CLOUDINARY_API_SECRET` — all three are required for image and video uploads when using the default Cloudinary provider.
- `STORAGE_PROVIDER=s3` and the S3 variables in `ToplineMobile-saver/.env.example` — only if intentionally using S3 instead of Cloudinary.
- Firebase service-account values — required for server-side push notification delivery.

The API will not start without a working MongoDB connection. Media uploads return a configuration error until the selected media-storage provider is fully configured.

### Android

The default API URL is `https://topline-api.onrender.com/api/`. Override it with the Gradle property `TOPLINE_API_BASE_URL` in `ToplineAndroid/gradle.properties` or pass it to Gradle with `-PTOPLINE_API_BASE_URL=https://your-api-host/api/`.

Google sign-in requires `TOPLINE_GOOGLE_WEB_CLIENT_ID` to be configured for the Android build. Firebase push notifications additionally require the matching `google-services.json` in `ToplineAndroid/app/` and the server-side Firebase service-account variables.

Never commit real credentials, private keys, `.env` files, or Firebase service-account files.

## Build

Open `ToplineAndroid/` in Android Studio and allow Gradle sync to complete. Run the backend from `ToplineMobile-saver/` after installing its dependencies and configuring environment variables.

The GitHub Actions workflows compile the Android debug APK and run backend tests plus JavaScript syntax checks. These checks do not replace installing the APK and testing the live backend on a physical Android device.
